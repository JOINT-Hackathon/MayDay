## 범위와 한계

- 실제 사용자 기록은 Figma의 예시 내용으로 덮어쓰지 않았다. 시연 예시는 명시적으로 표시한다.
- 익명 공유 버튼은 다음에 확인할 행동을 담은 편집·복사 초안만 연다. 공개 게시나 자동 익명화 기능은 아니다.
- 브라우저 연결이 끝에 끊겨 최신 데스크톱 분석/보고서 스크린샷 저장은 완료하지 못했다. 해당 화면의 렌더링과 전환은 연결 종료 전에 확인했다.
- 실제 외부 AI 호출, 외부 서버 운영 데이터, 배포는 이번 디자인 작업에서 검증하지 않았다.
