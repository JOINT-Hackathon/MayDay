# 메이데이 캐릭터의 연속 움직임

## 현재 방식

원본의 부드러운 3D 렌더 질감을 유지한 단일 투명 이미지에 SVG 눈을 얹는다. 커서 이동 중 이미지 파일이나 포즈를 교체하지 않는다. 기존 정면·좌우 포즈 이미지 전환은 윤곽 차이로 끊김이 보여 제거했다.

- `public/mascot/mayday-face-base.png`: 정면 이미지에서 눈과 입을 imagegen으로 지운 고정 몸체.
- `public/mascot/mayday-center.png`: 베이스 로딩 전 또는 실패 시 보여주는 눈이 있는 이미지.
- `src/components/HeroMascot.jsx`: 눈과 몸의 연속 추적, 로딩 처리, 생명주기.
- `src/components/HeroMascot.css`: 몸의 작은 원근 회전, 별도 호흡, SVG 눈 깜빡임.

## 움직임

눈은 빠르게, 몸은 조금 늦게 커서를 따라온다. 매 프레임 시간 차이를 반영해 움직임을 보간하며, 프레임마다 React 상태를 갱신하지 않는다. 몸통은 최대 좌우 4px·상하 2px 이동, 좌우 5도·상하 3도·기울기 1.5도로 제한한다. 눈은 원본 좌표계에서 최대 좌우 20·상하 14만큼 움직이며, 몸통 레이어 안에 있어 항상 함께 따라간다.

눈 깜빡임은 타원 눈의 세로 크기를 연속적으로 줄이는 방식이다. 몸 이미지나 얼굴 전체를 교체하지 않는다. 호흡은 5초 주기로 1px 이동과 0.8% 크기 변화를 사용한다. 전체는 이미지 레이어 애니메이션이며 실제 3D 모델 회전은 아니다.

움직임이 목표 위치에 도달하면 JS 렌더 루프를 멈춘다. 터치 환경에서는 커서 추적 없이 대기 동작만 표시한다. 화면 밖·숨긴 탭에서는 동작을 멈추고, 실행 중 `prefers-reduced-motion` 변경도 반영한다.

## 검증

- Chrome에서 베이스/대체 이미지 로드 및 눈 정렬 확인.
- 커서를 반대 방향으로 옮긴 뒤 연속 10회 관측에서 몸통 위치 10개가 서로 달랐고, 이미지 주소는 모두 동일했다. 눈이 몸보다 먼저 목표 위치에 가까워지는 것을 확인했다.
- 재현: `npm run dev` 후 홈에서 커서를 천천히 좌우·상하로 움직인다. 몸의 윤곽과 질감은 유지되고, 눈과 몸이 연속적으로 따라와야 한다.
- `npm run build`, `git diff --check`로 빌드와 공백 오류를 검사한다.

## 얼굴 정렬과 커서 효과

입도 SVG의 작은 미소 선으로 분리해 눈과 같은 그룹에서 움직인다. 표정이 따로 움직여 보이지 않도록 얼굴의 이동 폭도 줄였다.

`PastelCursor.jsx`와 `PastelCursor.css`가 기본 커서를 유지한 채 360px 범위의 파스텔 초록 조명이 커서 주변을 밝히게 한다. 중앙 불투명도는 16%이며, 7단계 그라데이션으로 가장자리에서 완전히 투명해져 원형 경계가 드러나지 않도록 한다. 커서와 분리된 점처럼 보이지 않도록 위치 지연 없이 프레임 단위로 좌표를 반영한다. 효과는 클릭을 받지 않으며, 마우스가 있는 환경에서만 표시한다. 모바일·움직임 감소·고대비 설정에서는 숨기고, 탭이 숨겨지거나 커서가 창을 벗어나면 정리한다.
