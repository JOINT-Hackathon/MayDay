# Mayday 주요 기능 클레이 아이콘

2026-11-14 제작 및 적용. built-in image_gen 사용, 별도 API 키 불필요.

## 적용 결과

| 기능 | 파일 | 표시 크기 | 파일 용량 |
| --- | --- | --- | --- |
| 지금 할 일 순서 | `public/icons/clay-v1/zap.webp` | 44px | 7,604 bytes |
| 왜 그랬는지 돌아보기 | `public/icons/clay-v1/archive.webp` | 44px | 7,078 bytes |
| 팀장님께 보낼 메일 | `public/icons/clay-v1/mail.webp` | 44px | 8,328 bytes |
| 내 체크리스트 / 체크리스트에 담기 | `public/icons/clay-v1/shield.webp` | 28px, 팝업 제목 48px | 9,350 bytes |
| 마음 정리 저장 | `public/icons/clay-v1/heart.webp` | 28px | 8,952 bytes |

서비스용 5종 합계 41,312 bytes. WebP 너비 256px, 투명도 유지. 메일은 원본 비율에 맞춰 256 × 214px이며 나머지는 256 × 256px. 원본 PNG는 `originals/`에 보관했다. 변환은 cwebp q92, alpha quality 100을 사용했다.

기존 캐릭터의 연두·크림색과 부드러운 클레이 재질을 따르고, 감정 아이콘만 코랄색으로 구분했다. 큰 기능 카드의 20px 선 아이콘을 44px 이미지로 바꾸고 아이콘의 실루엣이 보이도록 작은 사각 배경을 없앴다. 이미지 내부 여백을 포함한 표시 크기이며 실제 물체의 크기는 더 작다.

## 수정 코드

- `src/components/Icon.jsx`: `variant="clay"`를 지정한 위치에만 WebP 사용. 로딩 실패 시 같은 이름의 기존 SVG로 대체. 장식 이미지의 중복 읽기를 방지.
- `src/components/ClayIcon.css`: 기능 카드의 크기 및 여백, 고대비 모드에서 SVG 표시.
- `src/components/ActionChecklist.jsx`: 할 일 순서 아이콘.
- `src/components/AnalysisAddons.jsx`: 돌아보기·메일·체크리스트 저장 아이콘.
- `src/App.jsx`: 헤더 체크리스트, 마음 정리 저장, 체크리스트 팝업 제목 아이콘.

```jsx
<Icon name="archive" variant="clay" size={44} />
```

## 검증

- `npm run check`: 기존 테스트 15/15, Vite 빌드, production smoke 모두 통과.
- 첫 테스트는 샌드박스의 로컬 포트 제한으로 실패했으며, 로컬 서버 실행이 허용된 환경에서 재실행해 통과했다.
- PNG 생성 결과를 눈으로 확인하고 WebP 5종의 크기 및 alpha 채널을 확인했다.
- 실제 빌드 화면에서 5종 이미지 로딩, 빈 alt, 가로 넘침 없음에 대한 assert를 통과했다.
- Chrome 데스크톱 및 390 × 844px 모바일 뷰에서 기능 카드의 표시와 줄바꿈을 확인했다.
- 저장된 캡처: `desktop.jpg`, `mobile.jpg`.
- 이미지 로딩 실패와 OS 고대비 모드는 코드로 대응했으나 해당 상태의 수동 재현은 수행하지 않았다. 실제 휴대폰과 외부 배포 환경은 미검증.

## 실행

`npm run dev` 후 로컬 화면에서 시연 예시를 열고 `수습 도와줘`를 누른다. 검증 시 빌드 화면은 http://127.0.0.1:5187 에서 실행했다. 서버 주소와 실행 여부는 이후 작업에서 다시 확인해야 한다.

## 생성 지시 요약

다음은 실제 생성 요청의 핵심 조건을 정리한 것이다. 최초 A안 비교 이미지와 기존 연두색 헤드셋 캐릭터를 참고 이미지로 사용했으며, 각 아이콘을 별도 요청으로 생성했다.

공통: 단일 오브젝트, 투명 배경, 정사각 캔버스 요청, 약 84–88%의 실루엣, 매끈한 클레이/실리콘 재질, 두껍고 둥근 모서리, 왼쪽 위의 부드러운 조명, 얕은 입체 각도, 작은 크기에서도 읽히는 단순한 형태. 연두 #b6e784, 세이지 #80b85c, 크림 #f4efd8, 깊은 초록 #28583e. 글자·캐릭터 얼굴·장식·좌대·유리 및 금속 질감 제외.

- zap: 둥근 끝과 넓은 팔을 가진 연두색 단일 번개 실루엣.
- archive: 둥근 연두색 보관함, 크림 뚜껑, 깊은 초록색 가로 홈.
- mail: 크림색 봉투 몸체와 둥근 연두색 삼각 덮개, 명확한 접힘선.
- shield: 연두색 방패 테두리, 크림색 안쪽 면, 두껍고 둥근 초록색 체크 표시.
- heart: 별도 장식 없는 통통한 코랄 하트, 복숭아색 하이라이트와 따뜻한 장밋빛 음영.
