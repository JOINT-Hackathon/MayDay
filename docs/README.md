## 문서 상태 읽는 법

- **현재 구현:** 실제 저장소 코드에서 확인한 동작. 배포나 외부 연동의 성공을 뜻하지 않는다.
- **이번 구현:** MVP + AI v0에서 만들기로 제안한 동작. 코드를 고치기 전에는 완료가 아니다.
- **후속 후보:** 사용자 검증이나 운영 조건을 확인한 뒤 결정할 기능.
- **검증 필요:** 실제 API 키, 사용자, 배포 환경 또는 외부 시스템에서 아직 확인하지 않은 사항.

제품 범위가 바뀌면 제품 MVP 명세와 로드맵부터 갱신한다. API 형식이나 저장 데이터가 바뀌면 계약·데이터 문서를 같은 변경에서 갱신한다. `README.md`의 실행 방법은 실제 코드가 바뀐 뒤에 맞춘다.

## 이번 문서 묶음의 경계

색·표면·움직임 기준은 [디자인 시스템](DESIGN_SYSTEM.md)에만 둔다. 기능 흐름과 접근성의 **동작 조건**은 요구사항 및 검증 계획에 포함한다. 가격, 시장 규모, 성과 수치, 고객 수요는 근거가 없어 확정하지 않는다.
