## 이번 변경

- OpenAI 전용 호출을 Claude Messages API로 전환. `.env`·예시 파일, 기본 Sonnet 5.5 설정, 선택적 workspace 헤더.
- 서버의 명시적 전송 동의 검사, JSON 스키마 응답 검사, 인증·결제·과부하·출력 잘림·거절·시간 초과 안내.
- 원문을 AI가 확인한 사실로 다시 채우지 않도록 수정. 결과 출처 표시 유지.
- 50초 화면 제한, 대기 시간 안내, 기본 정리 전환. API 키 없는 기존 흐름 유지.
- 직접 수정 시 동일 기록 갱신과 연결 체크리스트 갱신. 기존 편집 보고·메일 초안 보존.
- `npm run check`, `npm run ai:check`, `npm run demo` 명령과 발표·모델 가이드.
- 같은 작업 폴더에 추가된 TEAM5 공유 서버 기능은 보존했다. 이번 Claude 시연과 별개의 경로다.

총 입력 4,596·출력 983토큰이며 공식 표준 단가 적용 추정은 약 $0.0190/3건이다. 이것은 청구서 확정 금액이 아니다. 앞선 프롬프트 검증 3회와 아래 브라우저 요청은 별도다. 초안 지시를 보완하기 전에도 3건은 성공했지만 첫 체크리스트가 당장의 수습 행동에 치우쳐 있었으므로 재사용할 예방 행동을 명시했다.

샘플 3건의 수동 검토는 전체 정확도·평균 지연·실사용 효과·다양한 표현에 대한 안전성 평가가 아니다. 특히 모호한 상황에서 제안하는 행동은 여전히 사용자가 상황에 맞춰 검토해야 한다.

## 브라우저 시연

직접 확인한 동작:

- 빈 입력 시 오류와 입력 초점 이동.
- 기본 정리에서 감정·원인을 만들어 넣지 않음.
- 보고·메일 초안 열기, 체크리스트 저장.
- 직접 수정 후 기존 기록이 중복되지 않고 연결된 체크리스트가 갱신됨.
- 새로고침 후 기록 유지, 체크리스트 적용 표시.
- 모바일 점검 시 실제 CSS 너비 391px에서 문서 가로 너비 391px: 가로 넘침 없음. 기기별 전체 검증은 아님.
- 최종 Chrome 실연동: 전송 동의 → 실제 Claude 결과 → Claude 초안 표시 → 로컬 기록·체크리스트 저장.
- 최종 Chrome 검증에서 수집된 콘솔 error 0건.

실제 Claude 결과 화면: [캡처](../artifacts/mayday-claude-live.jpg). 이 결과의 사실·해석·감정·미확인 사항과 다음 발송 전 체크 항목을 화면에서 검토했다. 마지막 화면은 Chrome의 ‘🎤 발표 리허설’ 탭에 남겼다.

## 발표 실행

```bash
npm run demo
```

기본 주소는 `http://127.0.0.1:4173`. 이 작업에서 최종 빌드의 서버를 해당 주소에 실행해 두었다. 이미 실행 중일 때 새 서버를 중복 실행하지 않는다. 키를 수정하면 서버를 재시작한다. 로컬 기록은 브라우저·주소에 따라 달라진다.

## 미검증·제한

- 실제 외부 `chat-turn`, Haiku·Opus 모델 비교, 부하 시험, 모든 모바일 기기, Docker 실행은 미검증.
- 공유 서버의 실제 저장·운영 권한·개인 계정 분리는 이 검증 범위가 아니다. `서버 기록`은 계정 구분 없는 공유 화면이라는 안내가 있다.
- UI의 기본 로컬 기록과 공유 서버 저장은 독립적이다. 외부 전송·저장 기능을 실제 회사 데이터로 시연하지 않는다.
- 현장 네트워크·발표 장비·대회 평가표는 미확인. 실제 사용자 만족·업무 성과·수상 가능성을 검증하지 않았다.
- Git 커밋·푸시·외부 배포·대회 제출은 하지 않았다. API 키는 계속 비공개로 유지해야 한다.
