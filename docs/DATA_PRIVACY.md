# 메이데이 데이터·개인정보 기준

> 기준일: 2026-11-14 · 현재 코드의 저장·전송 사실과 향후 결정할 정책을 구분한다.

## 현재 저장 위치와 구조

브라우저 `localStorage`의 기존 키 `daeumjang.reflections.v1`에 기록 배열을 JSON으로 저장한다. 기존 로컬 기록에는 로그인·자동 동기화·백업이 없다. 별도 ‘서버 기록’ 화면은 TEAM5 백엔드 DB에 경험 본문·유형·분류, 체크리스트, 재발 방지 규칙을 저장한다. 서버 기록은 로그인한 계정별로 분리된다. 경험·항목·규칙 삭제 API를 제공하며 프로젝트 data 폴더의 파일 DB는 재시작 후 유지된다. 상세 정리·보고서·메일 초안도 서버에 저장할 수 있다. 로컬 기록 삭제는 서버 기록에 영향을 주지 않는다. 한 브라우저의 같은 출처에서 접근할 수 있으므로 공유 기기에서 민감한 내용을 입력하지 않도록 안내한다.

| 필드 | 현재 용도 | 저장 여부 |
| --- | --- | --- |
| `id`, `createdAt`, `mode`, `taskType` | 기록 식별·생성 시각·유형·업무 분류 | 저장 |
| `facts`, `interpretation`, `feeling` | 확인한 사실·내 해석·감정 | 저장 |
| `cause`, `causeStatus`, `impact`, `unknown` | 원인 확인 상태·영향·미확인 사항 | 저장 |
| `improvement`, `followUp`, `checklist` | 개선 행동·후속 질문·다음 점검 행동 | 저장 |
| `usedAt`, `outcome` | 마지막 적용 시각과 결과 문장 | 저장 |
| `rawText` | 작성 중인 상황 문장과 선택적 AI 요청 원문 | 별도 필드는 저장하지 않음. 기본 정리에서는 입력 문장이 `facts`에 포함되어 저장됨 |
| `source`, `actionChecked`, `addonDrafts` | 결과 출처, 완료 항목, 사용자가 편집한 보고·메일 초안 | 기록 저장 시 포함. 저장된 기록을 편집하면 갱신 |
| `aiConsent` | 이번 화면에서 AI 전송 동의 여부 | 현재 저장 기록에는 포함하지 않음 |

현재 `readRecords()`는 배열과 필수 식별·문자열 필드를 확인한 뒤 오래된 선택 필드를 기본값으로 채운다. 손상된 저장값은 오류를 표시하고 빈 목록을 보여준다. 현재 코드는 손상된 원본을 자동 복구하거나 백업하지 않는다.

## AI 전송

- 사용자가 AI 버튼을 누르고 전송에 동의하면 화면의 `rawText`와 경험 유형 `mode`가 자체 서버의 `/api/organize`로 전달된다.
- 서버는 요청을 외부 AI API로 전달한다. 현재 Claude 어댑터는 입력 내용을 Anthropic Messages API로 전달하며 제공자의 처리·보관 정책을 코드만으로 단정하지 않는다. 실제 운영 전 사용 중인 제공자 정책을 별도로 확인한다.
- AI 결과는 화면에서 수정 가능한 초안으로 취급한다. 사용자가 저장을 선택하기 전에는 기록으로 저장하지 않는다.
- 현재 서버 코드에는 요청 원문을 출력하는 로그가 없다. 배포 플랫폼의 접근 로그·오류 수집 설정은 배포 시 별도 확인한다.
- 회사명, 실명, 고객 정보, 내부 문서 원문 등 민감한 내용은 입력하지 않는다. 직접 정리 폼에 안내하며 홈 AI 전송은 별도 동의를 받는다.

## 삭제와 보존의 현재 한계

사용자는 ‘내 기록’에서 개별 기록을 삭제할 수 있다. 삭제하면 현재 브라우저의 해당 기록 배열에서 제거된다. 브라우저 저장소 전체 삭제도 가능하다. 로컬 기록의 서버 자동 동기화나 백업은 없다. 별도 서버 저장 내용은 소유 계정으로 로그인해야 조회·수정할 수 있다. 세션 쿠키와 계정 정보도 서버 DB에 저장되며 로그아웃 시 해당 세션을 폐기한다. 비밀번호는 salt를 포함한 PBKDF2 해시로 저장한다. 외부 AI로 이미 전송된 요청을 앱의 기록 삭제가 되돌리지는 못한다.

## 확장 전에 정할 사항

| 확장 | 먼저 결정할 항목 |
| --- | --- |
| 계정·서버 저장 | 수집 목적, 최소 필드, 인증·접근 제어, 보존 기간, 탈퇴·삭제 절차, 기존 로컬 기록 이전의 동의 |
| 분석 이벤트 | 개인 경험 본문을 수집하지 않는 이벤트 설계, 식별자·보존 기간, 사용자 안내 |
| 팀 공유 | 개인 기록과 공유 템플릿의 분리, 공개 범위, 공유 취소·삭제 |
| AI 모델 변경 | 전송 데이터, 제공자 처리 조건, 비용·사용량 한도, 오류·사실성 검증 |

위 항목은 **미결정**이다. 이를 현재의 개인정보 처리방침이나 보안 보장으로 소개하지 않는다. 실제 서비스 공개 전에 적용 법률과 운영 환경에 맞는 별도 검토가 필요하다.
