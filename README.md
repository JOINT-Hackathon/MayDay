# 다음장 — 사회초년생의 경험을 다음 행동으로

실수를 알아챘거나 업무에서 지적을 받았을 때, 감정과 할 일을 나눠 정리하고 **다음 업무에서 다시 볼 체크리스트 한 항목**을 만드는 해커톤 데모입니다.

## 바로 실행

Node.js 20.19 이상과 npm이 필요합니다.

```bash
npm install
npm run dev
```

브라우저에서 터미널에 표시된 주소(기본값 `http://127.0.0.1:5173`)를 엽니다. API 키 없이도 직접 입력, 기록 저장, 체크리스트 재사용을 시연할 수 있습니다.

## 선택: AI 정리 초안

AI 기능을 사용하려면 프로젝트 루트에서 `.env.example`을 `.env`로 복사한 뒤 서버용 `OPENAI_API_KEY`를 설정하고 개발 서버를 다시 시작합니다.

```bash
cp .env.example .env
npm run dev
```

브라우저가 서버의 `/api/organize`를 호출하며, API 키는 서버 환경 변수에서만 읽습니다. AI 버튼을 누를 때만 작성 중인 상황 문장이 전송됩니다. AI가 채운 내용은 **수정 가능한 초안**이며 사용자가 직접 확인해야 합니다. 키가 없거나 요청이 실패해도 직접 입력을 계속할 수 있습니다.

## 시연 흐름

1. 첫 화면에서 **실수를 알아챘어요** 또는 **지적을 받았어요**를 선택합니다.
2. 대화형 가이드가 질문을 하나씩 보여줍니다. 감정 트랙과 할 일 트랙 중 먼저 답할 순서를 고르고, 답을 쌓아 경험을 구체화합니다.
3. 대화가 끝나면 답이 들어간 정리 화면에서 **감정 트랙**(직접 확인한 사실·내 해석·감정)과 **할 일 트랙**(개선 포인트·후속 보고)을 검토하고 고칩니다.
4. 할 일 트랙에서 원인·영향을 선택적으로 적고 **블랙박스 보고서**(무슨 일·왜·영향·조치·재발 방지) 또는 **상사용 수습·후속 메일** 초안을 미리 봅니다.
5. 다음 업무에서 확인할 체크리스트 한 항목을 저장합니다. 저장 후 문서 초안을 복사하거나 텍스트 파일로 받을 수 있습니다.
6. **업무 시작**에서 업무 종류를 고르면 저장한 체크리스트가 다시 나타납니다. 사용 후 적용 결과를 기록할 수 있습니다.

두 문서는 사용자가 확인한 내용을 바탕으로 만든 **초안**일 뿐 자동 발송되지 않습니다. 원인·영향이 확인되지 않았으면 ‘확인 중’으로 표시됩니다. 실제 상황에 맞게 검토해야 합니다.

## 배포 확인

```bash
npm run build
npm run preview
```

정적 빌드 결과는 `dist/`에 생성됩니다. `npm run preview`와 `npm start`는 프런트엔드와 선택적 AI API를 같은 주소에서 제공합니다. 배포 환경에서도 AI를 사용하려면 서버 환경 변수에 `OPENAI_API_KEY`를 설정해야 합니다.

## 기록과 한계

- 기록은 이 기기의 브라우저 `localStorage`에만 저장됩니다. 로그인·서버 동기화·자동 백업은 없습니다. 공유 기기에서는 사용하지 않는 편이 좋습니다.
- 회사명, 실명, 고객 정보, 내부 문서 원문 등 민감한 내용을 입력하지 마세요. 저장한 기록은 **내 기록**에서 삭제할 수 있습니다.
- AI는 사실, 상대의 의도, 괴롭힘 여부를 판정하지 않습니다. 보고나 업무 결정을 대신하지도 않습니다.
- 체크리스트는 사용자가 작성한 개인 메모입니다. 효과나 업무 성과를 검증한 결과로 소개하지 않습니다.

## 주요 파일

- `src/App.jsx`: 두 입구, 트랙 선택, 입력·저장·재사용 화면
- `src/components/GuidedChat.jsx`: 질문을 하나씩 보여주는 대화형 입력 가이드
- `src/styles.css`: 반응형 화면 스타일
- `server.mjs`: 같은 출처의 프런트엔드 서버와 선택적 AI API
- `.env.example`: 서버 환경 변수 예시
