# 메이데이 — 경험을 다음 업무의 체크리스트로

실수를 알아챘거나 지적을 받았을 때 **직접 확인한 일**과 **다음 업무에서 확인할 행동**을 남기는 해커톤 MVP입니다. 기록은 업무 종류별로 다시 열고 적용 여부를 표시할 수 있습니다.

## 실행

Node.js 22 이상과 npm이 필요합니다.

```bash
npm ci
npm run dev
```

터미널에 표시된 주소(기본값 `http://127.0.0.1:5173`)를 엽니다. 개발 서버는 화면과 `/api/*`를 같은 주소에서 제공합니다. AI 키 없이도 직접 입력, 저장, 재조회가 가능합니다.

## TEAM5 백엔드 연동

[연동 실행 방법과 미지원 기능](docs/TEAM5_INTEGRATION.md)을 참고하세요. 하단 **서버 기록**에서 경험 저장, 최근 기록, 체크리스트, 재발 방지 규칙, 업무별 추천을 사용할 수 있습니다. 기존 분석 결과의 **이 경험을 서버에 저장하기**로도 연결됩니다.

## Figma 디자인 구현과 시연 순서

[Mayday 디자인 페이지](https://www.figma.com/design/JiW7EZGaBkJhjIv98mA6ps?node-id=84-213)의 1440px 화면을 기준으로 짙은 녹색 배경, 반투명 카드, 연두색 버튼, 감정·할 일 두 트랙을 구현했습니다. 원본 API는 권한 제한으로 읽을 수 없어 브라우저에서 확인한 화면과 프로젝트의 캐릭터 에셋을 사용했습니다. 아이콘은 코드로 구성했으며 Figma 원본과 픽셀 단위 일치를 보증하지 않습니다.

1. 홈에 상황을 입력하고 **메이데이 보내기**를 누릅니다. 빈 입력에는 오류와 입력 초점이 표시됩니다.
2. 바로 분석 결과에서 **마음 정리 / 지금 할 일**을 봅니다. AI 연결 없이도 입력한 문장과 업무 분류별 기본 행동 제안이 표시됩니다. 기본 정리는 AI 분석이 아니며 입력하지 않은 감정·원인은 만들어 넣지 않습니다.
3. **수습 도와줘**에서 할 일을 체크하고 블랙박스 보고서와 수습 보고 메일을 열 수 있습니다. 초안을 수정·복사·텍스트 파일 다운로드할 수 있습니다. **할 일 트랙 크게 보기**는 부가기능을 한 열로 보여줍니다.
4. **마음 정리 저장**은 두 트랙 기록을 저장합니다. **체크리스트에 담기**은 기록과 다음 업무 체크리스트를 함께 저장합니다. 저장하기 전 결과는 메모리에만 있습니다.
5. 헤더의 **내 체크리스트**를 눌러 업무 종류별 항목을 봅니다. 항목 추가·수정·삭제·순서 변경을 지원합니다. 체크한 후 **다 확인했어요**를 눌러야 적용 횟수와 시각이 기록됩니다. 팝업은 Escape로 닫히고 이전 버튼에 초점이 돌아옵니다.
6. 새로고침 후 최근 기록 또는 **내 기록**에서 체크 상태와 편집한 보고·메일 초안을 다시 확인합니다. **실패 라이브러리**는 공개 사용자 데이터가 아닌 시연 예시입니다.

기록이 없는 홈에는 실제 기록과 구분한 **시연 예시** 카드 3개를 표시합니다. 예시도 저장을 누르기 전까지 실제 기록에 추가되지 않습니다. **직접 정리하기**에서는 기존 두 트랙 폼을 계속 사용할 수 있습니다.

## Claude 연결과 발표 준비

프로젝트 루트의 `.env` 파일을 이미 준비했습니다. `ANTHROPIC_API_KEY`에 실제 키를 입력하고 서버를 재시작하세요. 기본 모델은 `claude-sonnet-5-5`입니다. 키는 채팅·커밋·프런트엔드 코드에 넣지 않습니다. 새로 체크아웃한 환경에 `.env`가 없을 때만 `.env.example`을 복사합니다.

```bash
npm run check     # 자동 테스트 + 빌드 + 서버 점검, 외부 AI 과금 없음
npm run ai:check  # 가상 문장 3건 실제 Claude 호출, 과금 발생
npm run demo      # 프로덕션 빌드 + 로컬 발표 서버 (기본 4173)
```

홈의 **직접 정리 · AI 설정**을 펼쳐 Claude 전송에 동의한 뒤 입력을 전송합니다. 동의하지 않으면 기본 정리를 사용합니다. 서버는 45초, 화면은 50초 제한을 두며 대기 중 **기본 정리로 계속**을 선택할 수 있습니다. `/api/status`는 키 설정 여부만 알려주며 실제 모델 접근 성공은 보증하지 않습니다. 2026-11-14에 최종 프롬프트 가상 샘플 3건과 브라우저 실호출을 확인했습니다. 새 키·새 배포 환경에서는 다시 검증해야 합니다.

- [Claude 설정·모델 비교·비용·오류 대응](docs/CLAUDE_SETUP.md)
- [5분 발표 대본·2분 시연·예상 질문](docs/PRESENTATION_GUIDE.md)
- [이번 검증 결과와 남은 확인](docs/RELEASE_CHECK.md)

보고서·메일은 정리된 필드를 앱에서 조합하는 수정 가능한 초안입니다. 별도 AI 메일 생성이나 자동 발송은 없습니다. 기록을 직접 수정하면 같은 기록과 연결된 체크리스트를 갱신합니다. 편집해 둔 보고·메일 초안은 보존하므로 수정된 사실과 맞는지 함께 확인해 주세요.

## 빌드·배포 확인

```bash
npm run build
npm run preview
```

빌드 결과는 `dist/`에 생성됩니다. `npm run preview`와 `npm start`는 빌드된 화면과 API를 같은 주소에서 제공합니다. 서버 헬스 체크는 `/api/health`입니다. `node scripts/smoke.mjs`로 키 없는 배포 형태의 기본 응답을 확인할 수 있습니다. Docker와 Node 배포 절차는 [배포 가이드](docs/DEPLOYMENT.md)에 있습니다. 정적 파일만 올리면 `/api/*`는 제공되지 않습니다.

## 데이터와 한계

- ‘내 기록’은 브라우저의 `localStorage`에, ‘서버 기록’에서 저장한 경험·체크리스트·재발 방지 규칙은 TEAM5 DB에 따로 저장됩니다. 자동 동기화되지 않으며 서버에는 사용자별 구분이 없습니다. 기본 서버 DB는 재시작 시 초기화됩니다. 기본 정리의 입력 문장은 저장 시 `facts`에 포함되므로 민감한 정보는 제외해 주세요. 로그인, 여러 기기 동기화, 자동 백업은 없습니다. 저장 키 `daeumjang.reflections.v1`은 이전 기록을 읽기 위해 유지합니다.
- 회사명, 실명, 고객 정보, 내부 문서 원문 등은 입력하지 마세요. AI 전송에 동의한 문장은 외부 AI 서비스로 전달됩니다. 앱에서 기록을 삭제해도 이미 보낸 요청을 되돌리지는 못합니다.
- AI와 문서 초안은 사실 판정이나 업무 결정을 대신하지 않습니다. 실제 상황에 맞게 검토하고 수정해야 합니다.
- 적용 표시는 사용자가 남긴 기록입니다. 재발 감소나 업무 성과의 증거가 아닙니다. 기록 하나에는 최근 적용 시각과 결과 문장만 남습니다.

## 검증

```bash
npm run build
node --test scripts/analysis.test.mjs
node scripts/smoke.mjs
```

- 분석 테스트: 기본 정리의 사실 보존·감정/원인 미생성, 업무 분류, 응답 정규화, 예시 구분, 이전 체크리스트 호환과 손상 데이터 보호.
- 브라우저 검증과 화면 캡처: [디자인 구현 검증](docs/FIGMA_IMPLEMENTATION.md).
- Claude Sonnet 5.5 실제 가상 샘플 3건과 브라우저 호출·저장을 확인했습니다. 세부 결과는 [검증 기록](docs/RELEASE_CHECK.md)을 참조하세요.

## 주요 파일

- `src/App.jsx`: 홈·직접 정리·분석 결과·내 기록·체크리스트 팝업과 저장
- `src/analysis.js`: 외부 요청 없는 기본 정리와 명시적 시연 예시
- `src/components/AnalysisAddons.jsx`: 보고서·메일 편집과 할 일 부가기능
- `src/components/ActionChecklist.jsx`: 할 일 완료 상태와 진행률
- `src/components/Icon.jsx`: 공통 선 아이콘
- `src/mayday.css`, `src/tokens.css`: Figma Dark 테마와 반응형 배치
- `src/styles.css`, `src/base.css`: 기존 공통·직접 정리 폼 스타일
- `src/checklistStore.js`: 체크리스트 저장 구조와 이전 기록 호환
- `server.mjs`: 화면, 상태·헬스 체크와 AI API
- `server/claude.mjs`, `server/reflection.mjs`: Claude 호출·응답 검증과 정리 프롬프트
- `scripts/check-claude.mjs`: 가상 샘플 실호출 점검
- `src/components/GuidedChat.jsx`: 기존 대화형 가이드. 기본 홈 흐름에서는 사용하지 않음

제품 범위, API, 데이터 정책은 [문서 안내](docs/README.md)에서 확인할 수 있습니다. Figma 구현 이후 화면 동작은 이 README와 [구현 검증](docs/FIGMA_IMPLEMENTATION.md)을 우선합니다.
